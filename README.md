##  Deskripsi Aplikasi

**MaNey** merupakan aplikasi mobile yang dirancang untuk membantu pengguna dalam mengelola keuangan pribadi secara sederhana, terstruktur, dan efisien. Aplikasi ini memungkinkan pengguna untuk mencatat pemasukan dan pengeluaran, memantau saldo keuangan, serta melihat riwayat transaksi secara berkala.

Pengembangan aplikasi MaNey dilakukan sebagai bagian dari pemenuhan Ujian Akhir Semester (UAS) Mata Kuliah Pemrograman Mobile 1 pada Program Studi Teknik Informatika Universitas Pelita Bangsa.

---

## Tujuan Pengembangan

Tujuan dari pengembangan aplikasi MaNey adalah sebagai berikut:
1. Membantu pengguna dalam mencatat dan mengelola keuangan pribadi.
2. Menyediakan tampilan antarmuka yang sederhana dan mudah digunakan.
3. Menerapkan konsep User Interface (UI) dan User Experience (UX) sesuai dengan materi perkuliahan.
4. Memenuhi seluruh ketentuan dan komponen UAS Pemrograman Mobile 1.

---

## Fitur Aplikasi

Aplikasi MaNey memiliki beberapa fitur utama, yaitu:
- **Splash Screen**  
  Menampilkan logo dan nama aplikasi sebagai tampilan awal aplikasi.

- **Halaman Login**  
  Digunakan untuk proses autentikasi pengguna sebelum masuk ke aplikasi.

- **Dashboard**  
  Menampilkan informasi saldo keuangan, grafik ringkasan transaksi, serta daftar transaksi terbaru.

- **Tambah Transaksi**  
  Digunakan untuk menambahkan data transaksi pemasukan maupun pengeluaran.

- **Riwayat Transaksi**  
  Menampilkan daftar transaksi yang telah dicatat oleh pengguna secara kronologis.

- **Ekspor Laporan**  
  Digunakan untuk mengekspor laporan transaksi keuangan.

---

##  Alur Penggunaan Aplikasi

1. Pengguna membuka aplikasi dan melihat **Splash Screen**.
2. Pengguna melakukan login melalui **Halaman Login**.
3. Setelah login berhasil, pengguna diarahkan ke **Dashboard**.
4. Pengguna dapat menambahkan transaksi melalui menu **Tambah Transaksi**.
5. Pengguna dapat melihat transaksi yang telah dilakukan pada menu **Riwayat Transaksi**.
